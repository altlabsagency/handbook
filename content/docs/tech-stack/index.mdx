Most of what we build is a web platform, a mobile app, or both, often with AI features. New projects start from the defaults below.

## Our default stack

| Area           | Default                                                                                      |
| -------------- | -------------------------------------------------------------------------------------------- |
| Web&nbsp;apps  | Laravel, Inertia, React and TypeScript, with Tailwind CSS and shadcn/ui |
| Mobile&nbsp;apps | Flutter with Provider, and Firebase for push notifications and crash reporting               |
| AI             | Laravel AI SDK, with the provider chosen per project                          |
| Database       | MySQL, with Laravel's database drivers for queues and cache                                  |
| Hosting        | AWS EC2 managed with Vito Deploy, or Azure, depending on the client                          |
| Source&nbsp;control | Git and GitHub, with GitHub Actions for CI                                                           |

We also maintain projects built on other technologies, mostly inherited from clients. See [Other tech we support](/docs/tech-stack/other-tech).
